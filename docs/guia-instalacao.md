# Guia de primeira execução

1. Finalize a instalação do Ubuntu no SSD e reinicie sem o pendrive de instalação.
2. Entre com seu usuário local.
3. Conecte-se à internet e abra o Terminal (`Ctrl+Alt+T`).
4. Obtenha esta pasta por download ZIP ou pelo repositório GitHub quando for publicado.
5. No terminal, acesse a pasta onde estiver o `README.md`.
6. Examine o conteúdo de `scripts/setup-ubuntu.sh`.
7. Execute `bash scripts/setup-ubuntu.sh` e digite sua senha quando o `sudo` pedir.
8. Caso a atualização exija reinicialização, reinicie normalmente após a conclusão.

Não execute o script no modo Live USB. Ele não apaga nem restaura dados. O backup de projetos e jogos deve ser recuperado separadamente.
